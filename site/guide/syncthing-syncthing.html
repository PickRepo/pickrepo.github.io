Nedir?

Seçtiğin klasördeki dosyaları, birbirine izin verdiğin cihazlarda aynı tutan bir uygulama.

Ne işe yarar?

Bir bilgisayardaki değişiklikleri başka bir bilgisayara elle taşımadan aktarabilirsin.

Nasıl kullanılır?

İlk kullanımda yalnızca deneme klasörünü paylaş. İçine önemsiz bir metin dosyası koy, iki cihazdaki Syncthing açıkken dosyanın diğer cihazda görünmesini bekle. Sonra dosyayı değiştirerek değişikliğin aktarılmasını izle. Önemli belgeleri taşımadan önce ayrı yedeğini al; silme işlemleri de eşitlenebilir.

Kurulum gereksinimleri

İki cihazı eşleştirmen gerekir. İlk denemeyi önemli dosyalar yerine boş bir klasörle yap.

Sınırlar ve riskler

Bir dosyayı silmek diğer cihazda da silinmesine yol açabilir. Eşitleme, ayrı bir yedeğin yerine geçmez.

Nasıl kurulur?: Windows

Aşağıdaki adımlar kaynaklardan derlenmiştir; bu sitede kurulup denenmemiştir.

Başlamadan önce

  • İki bilgisayar, her ikisinde de internet/ağ bağlantısı ve programı çalıştırma izni.
  • Ayarlar → Sistem → Hakkında bölümünden işlemci türünü kontrol et. İndirmede bu türe uygun Windows paketini seç.
  1. Aşağıdaki resmî indirme bağlantısını aç. İşletim sistemi ve işlemci türünle eşleşen paketi indir; emin değilsen rastgele bir paket seçme.
  2. İndirilen sıkıştırılmış dosyayı sağ tık → Tümünü ayıkla ile bir klasöre çıkar. Klasördeki syncthing.exe dosyasını aç. Beklemediğin bir güvenlik uyarısını atlatmak için korumayı kapatma.
  3. Tarayıcıda Syncthing yönetim sayfasının açılmasını bekle. Otomatik açılmazsa program çalışırken tarayıcının adres çubuğuna http://localhost:8384 yaz. Bu adres kendi bilgisayarındaki uygulamaya gider; Repo Atlas’a dosya yüklemez.
  4. Aynı işlemi ikinci bilgisayarda yap. Her cihazda Actions → Show ID bölümündeki cihaz kimliğini bul. Add Remote Device ile diğer cihazın kimliğini ekle. İki tarafta da karşılıklı eşleştirme gerekir.
  5. Add Folder ile yalnızca deneme için oluşturduğun klasörü seç ve eşleştirdiğin cihazla paylaş. Diğer cihazda gelen klasör paylaşımını kabul edip hedef klasörü seç.
  6. Deneme klasörüne önemsiz bir metin dosyası koy. İki program da açıkken diğer cihazda görünmesini bekle.

Başarı işareti: Deneme dosyası diğer cihazda görünür; eşitleme tamamlanınca klasör durumu Up to Date olur.

Takılırsan

  • Bağlanmıyorsa iki programın da açık olduğunu ve kimlikleri karşılıklı eklediğini kontrol et.
  • Bu taşınabilir programı çalıştırmak, Windows başlangıcında otomatik açılacağını garanti etmez. Başlangıç ayarlarını ayrıca resmî belgelerden incele.

An application that keeps selected folders in sync between devices you explicitly pair.

What is it?

An application that keeps selected folders in sync between devices you explicitly pair.

What is it useful for?

Move changes between your own computers without copying every file by hand.

How do you use it?

For first use, share only a test folder. Add an unimportant text file and keep Syncthing running on both devices until it appears on the other device. Edit the test file and check that the change is transferred. Back up important documents separately before adding them; deletions can synchronise too.

Installation requirements

You need to pair two devices. Start with an empty test folder, not important files.

Limitations and risks

Deleting a file may delete it on the other device too. Synchronisation is not an independent backup.

How to install: Windows

The steps below are based on the sources; installation was not tested on this site.

Before you start

  • Two computers with network access and permission to run applications.
  • Check the processor type in Settings → System → About and select the matching Windows download.
  1. Open the official download link below. Download the Windows package matching your processor; do not guess if you are unsure.
  2. Right-click the downloaded archive → Extract All. Open syncthing.exe from the extracted folder. Do not disable security protection to bypass an unexpected warning.
  3. Wait for the management page to open in your browser. If it does not, type http://localhost:8384 into the address bar while Syncthing is running. This opens your own computer’s application; it does not upload files to Repo Atlas.
  4. Repeat on the second computer. On each device use Actions → Show ID to find its device ID, then Add Remote Device to add the other computer. Pairing must be mutual.
  5. Use Add Folder to select a new test folder and share it with the paired device. Accept the folder invitation on the other device and choose its destination.
  6. Put an unimportant text file in the test folder. Keep both programs running and wait for it to appear on the other computer.

Success check: The test file appears on the other device and the folder eventually shows Up to Date.

If something goes wrong

  • If it does not connect, check that both programs are running and each device has added the other’s ID.
  • Running this portable program does not guarantee automatic startup with Windows. See the official documentation for startup options.
