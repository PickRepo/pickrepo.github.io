Nedir?

PDF ve Office gibi çeşitli dosyalardaki metni Markdown denen düz metin biçimine dönüştüren bir araç.

Ne işe yarar?

Belgeleri metin olarak incelemek veya sonraki işlemlere hazırlamak için kullanabilirsin.

Nasıl kullanılır?

Yukarıdaki kurulum bölümünde hazırladığın deneme klasörünü kullan. Gizli bilgi içermeyen, seçilebilir metni olan bir PDF kopyasını example.pdf adıyla koy. Gösterilen dönüştürme komutuyla document.md üret; bu adla dosya zaten varsa önce farklı çıktı adı seç. Sonucu Not Defteri ile açıp kaynak PDF ile karşılaştır. Taranmış görüntü veya karmaşık düzenlerde eksik metin olabilir.

Kurulum gereksinimleri

Bu, çift tıklayıp kullanılan bir masaüstü uygulaması değil. Python kurulumu ve komut penceresi kullanımı gerekir; diğer örneklere göre daha teknik.

Sınırlar ve riskler

Belgenin sayfa tasarımı aynen korunmaz. Taranmış PDF’ler ve bazı dosya türleri ek araç gerektirebilir. İsteğe bağlı bulut/AI özellikleri ek ücret veya veri aktarımı getirebilir; bu rehber onları etkinleştirmez.

Nasıl kurulur?: Windows

Aşağıdaki adımlar kaynaklardan derlenmiştir; bu sitede kurulup denenmemiştir.

Başlamadan önce

  • Python 3.10–3.14 gerekir; bu aralığın dışındaki bir sürümü otomatik olarak uygun sayma.
  • Python yoksa aşağıdaki resmî Python bağlantısından desteklenen sürümü kur. Kurulum seçenekleri sürüme göre değişebilir; resmî Windows yardımını izle.
  • Yalnızca deneme dosyaları için yeni ve boş bir klasör oluştur. Dosya Gezgini’nde o klasörü aç; adres çubuğuna powershell yazıp Enter’a bas. Komutları açılan pencerede, sırayla çalıştır.
  1. Python sürümünü kontrol et. Çıktı 3.10–3.14 aralığında değilse sonraki adıma geçme. Komut bulunmuyorsa önce Python kurulumunu düzelt.
    python --version
  2. Bu klasörde .venv adlı ayrı bir araç ortamı oluştur. Böylece bu denemenin Python paketleri diğer projelerinkilerle karışmaz.
    python -m venv .venv
  3. MarkItDown’ı bu ayrı ortama kur. Komut internetten paket indirir. [all], isteğe bağlı dönüştürme bağımlılıklarını da kurduğu için indirme daha büyük olabilir; bulut hizmeti aboneliği başlatmaz.
    .\.venv\Scripts\python.exe -m pip install "markitdown[all]"
  4. Gizli bilgi içermeyen bir PDF’nin kopyasını bu klasöre koy ve example.pdf adını ver. Aynı yerde document.md varsa önce farklı bir ad seç; çıktı dosyasının üzerine yazılabilir. Dönüştürme komutunu çalıştır.
    .\.venv\Scripts\markitdown.exe example.pdf -o document.md
  5. Oluşan document.md dosyasını Not Defteri ile aç. Kaynak PDF’deki birkaç cümleyle karşılaştır; eksik veya bozuk metin bulunabilir.

Başarı işareti: Klasörde document.md oluşur ve metin içerir. Bu, tüm belgelerin kusursuz dönüştürüleceği anlamına gelmez.

Takılırsan

  • Python bulunamıyorsa PATH adı verilen komut arama ayarına takılmış olabilirsin. Rastgele yönetici komutları denemek yerine resmî Windows/Python yardımını izle.
  • Dosya bulunamadı hatasında PowerShell’in deneme klasöründe açık olduğunu ve example.pdf dosya adını kontrol et.
  • Boş çıktı, taranmış görüntüden oluşan PDF’ye işaret edebilir. OCR veya ücretli AI hizmetini otomatik açmak yerine önce resmî desteklenen biçimler bölümünü incele.

What is it?

A tool that converts text in files such as PDFs and Office documents into a plain-text format called Markdown.

What is it useful for?

Read documents as text or prepare them for further processing.

How do you use it?

Use the test folder prepared in the installation steps above. Copy a non-sensitive PDF containing selectable text into it as example.pdf. Use the displayed conversion command to create document.md; choose another output name if that file already exists. Open the result in Notepad and compare it with the PDF. Scanned images and complex layouts may produce incomplete text.

Installation requirements

This is not a point-and-click desktop app. It requires Python and a command window, making it more technical than the other examples.

Limitations and risks

Page layout is not preserved exactly. Scanned PDFs and some formats may need extra tools. Optional cloud/AI features may involve charges or data transfer; this guide does not enable them.

How to install: Windows

The steps below are based on the sources; installation was not tested on this site.

Before you start

  • Requires Python 3.10–3.14; do not assume versions outside this range are supported.
  • If Python is missing, install a supported version from the official Python link. Installer options vary; follow the official Windows instructions.
  • Create a new empty folder for test files. Open it in File Explorer, type powershell in its address bar and press Enter. Run the following commands in order in that window.
  1. Check the Python version. If the output is not between 3.10 and 3.14, stop here. If the command is missing, fix the Python installation first.
    python --version
  2. Create a separate tool environment named .venv in this folder. This keeps these Python packages separate from those of other projects.
    python -m venv .venv
  3. Install MarkItDown into that environment. This downloads packages from the internet. [all] also installs optional conversion dependencies, so the download may be larger; it does not subscribe you to a cloud service.
    .\.venv\Scripts\python.exe -m pip install "markitdown[all]"
  4. Copy a non-sensitive PDF into this folder and name the copy example.pdf. If document.md already exists, choose a different output name first: output may be overwritten. Run the conversion command.
    .\.venv\Scripts\markitdown.exe example.pdf -o document.md
  5. Open the resulting document.md in Notepad. Compare a few sentences with the source PDF; text may be missing or imperfect.

Success check: document.md appears in the folder and contains text. This does not guarantee perfect conversion for all documents.

If something goes wrong

  • If Python cannot be found, its command search path may not be configured. Follow the official Python/Windows help instead of trying arbitrary administrator commands.
  • For a file-not-found error, check that PowerShell is open in your test folder and that the file is named example.pdf.
  • An empty result may mean the PDF contains scanned images. Check the official supported formats instead of automatically enabling OCR or a paid AI service.
