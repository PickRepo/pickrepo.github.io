Nedir?

Yapay zekâ modellerini bilgisayarına indirip çalıştırabilen bir uygulama. Model, yanıt üretmek için kullanılan büyük bir veri dosyası gibi düşünülebilir.

Ne işe yarar?

Kendi bilgisayarının gücüyle bir yapay zekâ modeline soru sorabilirsin.

Nasıl kullanılır?

Programın kurulması bir modelin de hazır olduğu anlamına gelmez. Aşağıdaki resmî model kitaplığından bilgisayarına uygun bir model seç; indirme boyutunu, lisansını ve modelin kendi kullanım adımlarını kontrol et. İlk denemede kişisel bilgi içermeyen kısa bir soru sor. Yerel model ile bulut modelini karıştırma; bu rehber belirli bir modelin bilgisayarında çalışacağını garanti etmez.

Kurulum gereksinimleri

Programın yanında model de indirilir. Depolama, bellek ve işlemci ihtiyacı modele göre değişir; her bilgisayar her modeli çalıştıramaz.

Sınırlar ve riskler

Yerel çalıştırma ile bulut seçenekleri aynı değildir. Seçtiğin modelin nerede çalıştığını ve lisansını kontrol et. Yanıtlar hatalı olabilir; doğruluğu garanti edilmez.

Nasıl kurulur?: Windows

Aşağıdaki adımlar kaynaklardan derlenmiştir; bu sitede kurulup denenmemiştir.

Başlamadan önce

  • Windows 10 22H2 veya daha yeni sürüm; indirme için internet.
  • Resmî Windows belgesine göre uygulama kurulumu için en az 4 GB boş alan gerekir. Modeller bunun dışında ek alan ister; indirmeden önce boyutu kontrol et.
  1. Resmî indirme sayfasında Windows sürümünü seç; OllamaSetup.exe yükleyicisini indir.
  2. İndirilen yükleyiciyi aç ve kurulum penceresindeki adımları tamamla. Windows sürümü normalde kendi kullanıcı hesabına kurulur; yönetici yetkisi gerektirmez.
  3. Başlat menüsünden Ollama’yı aç. Ardından Başlat menüsüne PowerShell yazıp Windows PowerShell’i aç. Bu pencere, aşağıdaki komutu yazacağın yerdir.
  4. Aşağıdaki komutu yazıp Enter’a bas. Bu komut kurulu programın sürümünü gösterir; model indirmez ve ücretli hizmet başlatmaz.
    ollama --version
  5. Model seçmek için aşağıdaki resmî model kitaplığını incele. Boyutunu, lisansını ve bilgisayarına uygunluğunu kontrol et; ardından ilgili modelin resmî kullanım adımını izle.

Başarı işareti: Komut bir Ollama sürüm numarası döndürür. Bu yalnızca programın kurulu olduğunu gösterir; modelin başarıyla çalıştığı anlamına gelmez.

Takılırsan

  • “ollama tanınmıyor” hatasında PowerShell’i kapatıp yeniden aç. Kurulumu tamamladığını kontrol et.
  • Model yavaşsa veya bellek hatası veriyorsa daha küçük bir modeli değerlendirmeden önce resmî gereksinimleri incele.

Nasıl kurulur?: macOS

Aşağıdaki adımlar kaynaklardan derlenmiştir; bu sitede kurulup denenmemiştir.

Başlamadan önce

  • macOS Sonoma 14 veya üstü. Apple M serisinde CPU/GPU desteği; Intel Mac’te yalnızca CPU desteği.
  • Model dosyaları için ek boş alan gerekir. Modeli indirmeden önce boyutunu kontrol et.
  1. Resmî indirme bağlantısından Mac sürümünü indir ve ollama.dmg dosyasını aç.
  2. Ollama simgesini Applications / Uygulamalar klasörüne sürükle. Uygulamalar’dan Ollama’yı aç.
  3. Komut satırı bağlantısı oluşturma izni sorulursa, resmî olarak indirdiğin uygulamaya ait olduğundan emin ol. Spotlight aramasından Terminal’i aç. Terminal, kısa metin komutlarının yazıldığı uygulamadır.
  4. Aşağıdaki komutu yazıp Enter’a bas. Yalnızca sürümü kontrol eder; model indirmez.
    ollama --version
  5. İlk model için resmî kitaplıktan bilgisayarına uygun bir model seç. Lisansını ve dosya boyutunu kontrol ederek o modelin resmî adımlarını izle.

Başarı işareti: Terminal bir sürüm numarası gösterir. Model kurulumu ve yanıt üretmesi ayrı bir sonraki adımdır.

Takılırsan

  • Komut bulunamazsa Ollama’nın açık olduğunu ve komut satırı bağlantısı iznini kontrol et.
  • Model çalışmıyorsa modeli tekrar tekrar indirmeden önce resmî donanım gereksinimlerine bak.

What is it?

An application that can download and run AI models on your computer. Think of a model as a large data file used to generate responses.

What is it useful for?

Ask an AI model questions using your own computer’s processing power.

How do you use it?

Installing the application does not mean a model is ready. Choose a suitable model in the official library below and check its download size, licence and own usage instructions. For your first test ask a short question without personal information. Distinguish local and cloud models; this guide does not guarantee that a particular model will run on your computer.

Installation requirements

You download a model as well as the application. Storage, memory and processing needs depend on the model; not every computer can run every model.

Limitations and risks

Local execution and cloud options are different. Check where your selected model runs and its licence. Responses can be wrong.

How to install: Windows

The steps below are based on the sources; installation was not tested on this site.

Before you start

  • Windows 10 22H2 or later and internet access for downloads.
  • The Windows documentation requires at least 4 GB free for the application. Models need additional space; check the model size before downloading.
  1. Choose Windows on the official download page and download OllamaSetup.exe.
  2. Open the installer and complete its prompts. The standard Windows installation uses your account and does not require administrator rights.
  3. Open Ollama from the Start menu. Then search for PowerShell in Start and open Windows PowerShell. This is where you type the command below.
  4. Type the command below and press Enter. It shows the installed application version; it does not download a model or activate a paid service.
    ollama --version
  5. Use the official model library below to choose a model. Check its size, licence and suitability for your computer, then follow that model’s official usage instructions.

Success check: The command prints an Ollama version. This only verifies the application is installed, not that a model can run successfully.

If something goes wrong

  • If “ollama is not recognised” appears, close and reopen PowerShell and check that installation completed.
  • If a model is slow or runs out of memory, check its official requirements before trying a smaller model.

How to install: macOS

The steps below are based on the sources; installation was not tested on this site.

Before you start

  • macOS Sonoma 14 or later. Apple M-series supports CPU/GPU; Intel Macs use CPU only.
  • Allow additional space for model files and check the model size before downloading.
  1. Download the Mac version from the official link and open ollama.dmg.
  2. Drag Ollama into Applications, then open it from Applications.
  3. If asked to create a command-line link, verify the request belongs to the official app you downloaded. Open Terminal using Spotlight; Terminal is the app where you type short text commands.
  4. Type the command below and press Enter. This checks the version without downloading a model.
    ollama --version
  5. For your first model choose a suitable model in the official library. Check its licence and download size, then follow its official instructions.

Success check: Terminal prints a version number. Installing a model and generating a response are separate next steps.

If something goes wrong

  • If the command is not found, check that Ollama is open and its command-line link was allowed.
  • If a model fails, check official hardware requirements before repeatedly downloading it.
